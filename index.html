How it works

  • Cap is five minutes. Longer files are rejected before the engine starts.
  • Work happens in this tab. No account. No server copy.
  • First run downloads the FFmpeg engine (~25 MB). After that it stays cached.
  • Use footage you recorded or own. Snatcher copies the soundtrack. It does not clean rights.
