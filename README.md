# Snatcher

Free PWA. Drop a video up to five minutes. Get the audio. The file never leaves the device.

- Engine: [ffmpegwasm/ffmpeg.wasm](https://github.com/ffmpegwasm/ffmpeg.wasm) (highest-rated in-browser FFmpeg, 17.8k stars)
- Same encode path as the workspace `audio-snatcher` skill: `libmp3lame -q:a 2`, AAC/M4A fallback
